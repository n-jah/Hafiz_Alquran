# Hafiz — Quran Memorization Review App

An offline-first Android app that generates adaptive, randomized review tests from a local Quran verse database, with real-time grade tracking.

Built by **Ahmed Nagah** — Software Engineer (Android/Kotlin). Portfolio: [nagah.vercel.app](https://nagah.vercel.app)

## What it is
Helps users review memorized Quran by generating dynamic quizzes over a chosen range (Juz / Surah / page) and tracking performance over time.

## My role
Solo developer — architecture, UI, question-generation logic, and the local data layer.

## Tech stack
- Kotlin, MVVM (ViewModel + LiveData)
- Room (offline verse storage)
- Coroutines (async question generation)
- Material UI

## Key capabilities
- Dynamic, non-repeating question generation over any verse range
- Customizable tests (Juz range, question count, lines per question)
- Real-time grade tracking and average-score history
- Fully offline (local Room DB)

## Impact
- **1,000+ students** use the app for memorization review
- Automated grading reduced manual correction time (~40%)
